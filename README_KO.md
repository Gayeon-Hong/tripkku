# 오이타 친구용 v16 · 작은 지구 버튼 + 짐 보관 안내

## 바뀐 부분

- 기존 일본풍 레이아웃을 유지합니다. 큰 여행 꾸미기 화면은 추가하지 않았습니다.
- 작은 지구 옆에 제목 없이 `☀ 낮 / ☾ 밤 / 😄 / 😠 / 😴 / 🥰` 버튼만 추가했습니다.
- 낮/밤은 지구 그림의 배경을 바꿉니다. 페이지 전체 테마는 기존 아이보리 그대로입니다.
- 표정은 이모지 표시만 바뀌는 것이 아니라 지구 위의 눈·입 모양이 실제로 달라집니다.
- 지구 설정은 각자 기기에 저장됩니다. 친구의 설정을 덮어쓰거나 공동 여행 DB에 쓰지 않습니다.
- 인스타 링크, 챗봇, 공유 초대, 공용 정산은 기존 기능을 유지합니다.

## 적용 순서 (Supabase SQL 또는 API 키 변경 없음)

1. GitHub의 `tripkku` 저장소를 열고 현재 파일을 백업합니다.
2. 이 ZIP을 압축 해제합니다.
3. `website` 폴더 안의 `index.html`, `app.js`, `style.css`, `sw.js`, `earth-controls.js`를 GitHub 최상위에 올립니다.
   - 기존 파일 4개는 교체, `earth-controls.js`는 신규 추가입니다.
   - `website` 폴더 자체를 저장소에 넣는 것이 아니라 안의 파일을 최상위에 올립니다.
4. `website/assets` 안의 PNG 파일을 GitHub `assets` 폴더에 추가/교체합니다.
   - `earth-base-light.png`와 `earth-base-dark.png`가 반드시 필요합니다.
   - 원래의 `earth.png`, `favicon.png`도 함께 제공하지만 다른 assets 파일은 지우지 않습니다.
5. Commit changes 후 GitHub Pages 배포가 완료되면 사이트를 새로고침합니다.
   - 파일 참조는 `?v=16.1`로 갱신되어 있습니다.
   - 기존 `config.js`는 교체하거나 삭제하지 않습니다. 이 ZIP에는 config.js를 넣지 않았습니다.
6. 이미 만들어 둔 여행방은 2일 차의 `짐 보관 반영` 버튼을 한 번 누릅니다.
   - 또는 `교통·예약` 화면의 같은 버튼을 누릅니다.
   - 새 여행방은 처음부터 변경된 짐 보관 안내가 들어갑니다.

기존 v14/v15 공동 편집 설정이 완료되어 있다는 전제의 화면 수정 패치입니다. 기존 Supabase 테이블·정책·Edge Function을 재설정할 필요가 없습니다. 실제 배포와 서버 반영은 사용자 계정에서 진행해야 합니다.

## 짐 보관 계획을 이렇게 정리했습니다

현재 예약한 두 숙소는 가마지옥 도보권이 아닙니다.

- HOTEL MYSTAYS Oita: 오이타 시내, JR 오이타역 도보권.
- 유후 모미지: 유후인 가와키타.
- 가마지옥: 벳푸 간나와.

따라서 다음 동선으로 안내합니다.

첫날: MYSTAYS에 먼저 캐리어 맡기기 → 이치란 → 몽벨 → 이자카야.
둘째 날: 체크아웃 → 벳푸역 WANDER COMPASS의 직원에게 짐 맡기기 → 가마지옥 → 같은 보관소에서 회수 → 역 서쪽 출구 → 유후인행 버스 → 모미지 셔틀 약 5분.

유인 보관소는 코인로커가 아닙니다. 보관 가능 여부·크기별 요금·접수와 회수 마감은 이용 전에 확인하세요. 실제로 결제하기 전까지 보관료를 정산에 자동으로 추가하지 않습니다.

숙소를 가마지옥 근처로 변경하고 숙소가 체크인 전 보관을 허용하는 경우에만 숙소 보관 경로를 사용하면 됩니다. 현재 예약을 임의로 변경하거나, 가까운 숙소라는 가정으로 동선을 재작성하지 않았습니다.

이번 패치는 이전 버전의 기본 짐보관 문구가 남아 있는 일정만 변경합니다. 사용자가 이미 수정한 제목·메모·장소는 덮어쓰지 않습니다. 기존 일정 시간, 숙소 예약, 지출 내역, 인스타 링크도 유지합니다. 직접 고친 보관 안내는 일정의 수정 버튼에서 수동으로 바꿀 수 있습니다.

## 검사 범위

- JavaScript 구문 검사 통과: app.js, earth-controls.js.
- Chromium 144 로컬 DOM 렌더링: 320 / 360 / 390 / 430 / 768 / 850 / 1024 / 1440px.
- 6개 버튼 클릭, 키보드 Enter/Space, 선택 표시, 지구 배경·눈·입 변경, 저장된 설정 읽기 검사.
- 보관 안내 반영 시 숙소비 96,200원/517,514원, 기존 수정 시간·메모·인스타 링크 보존 확인.
- 두 사용자 동시 저장 충돌의 재시도 및 저장 실패 시 기존 데이터 보존을 모의 테스트.

이 환경에서는 실제 사이트 주소 이동이 제한되어 HTML/CSS/JS를 로컬 브라우저 DOM에 주입해 검사했습니다. Supabase, 날씨, localStorage는 테스트 대역을 사용했습니다. 실제 GitHub Pages의 파일 로딩, 실제 브라우저 영구 저장, 두 계정의 실시간 공동 편집은 배포 후 확인이 필요합니다. 테스트에서 실제 Supabase나 Gemini API에 쓰기 요청을 보내지 않았습니다.

`verification` 폴더에는 실제 로컬 렌더링 캡처와 테스트 결과가 있습니다. 캡처의 로그인/연결 상태는 테스트용이며 실제 서버 연결 확인 화면이 아닙니다.
