# 트립꾸 · 쿠폰 결제 연동 (토스페이먼츠, 웹·MS 앱) — 2026-11-12

테스트 클라이언트 키가 들어가서 **결제 버튼이 켜져 있다**(`next/app.js` 의 `PAY.clientKey`, 2026-11-12). 실제 판매는 가맹 심사 통과 후 live 키로 바꿔야 한다.
아직 실제 결제로 시험해 보지 못했으니 반드시 테스트 키로 먼저 확인할 것.

## 직접 해야 하는 것

1. **토스페이먼츠 가입**: https://www.tosspayments.com → 개발자센터에서 **테스트 키**(클라이언트 키 `test_ck_…`, 시크릿 키 `test_sk_…`) 확인. 결제창(API 개별 연동)용 키를 쓴다.
2. **SQL 실행**: Supabase → SQL Editor → `sql/2026-11-12_payments.sql`.
3. **서버 함수 올리기**: Supabase → Edge Functions → 새 함수 이름 `tripkku-pay-confirm` → `supabase/functions/tripkku-pay-confirm/index.ts` 내용을 붙여넣고 배포.
4. **비밀 값 넣기**: Supabase → Edge Functions → Secrets → `TOSS_SECRET_KEY` = 시크릿 키. (저장소·채팅에 올리지 말 것)
5. **클라이언트 키 알려 주기**: `test_ck_…` 를 Claude 에게 알려 주면 `PAY.clientKey` 에 넣어 결제 버튼을 켠다(공개해도 되는 값).
6. 테스트 결제로 쿠폰이 들어오는지 확인 → 토스페이먼츠 **가맹 심사**(사업자등록증, 사이트의 사업자 정보·환불 규정 표시 필요) → 통과하면 라이브 키로 3~5번 반복.

## 동작

- 동선 영상 창의 "쿠폰 1장 사기 · 1,000원" → 서버가 주문을 만들고(가격은 서버가 정함) → 토스페이먼츠 결제창 → 앱으로 돌아오면 서버 함수가 주문자·금액을 확인하고 토스에 승인을 요청 → 쿠폰 지급.
- 같은 주문으로 쿠폰이 두 번 들어가지 않는다. 금액이 바뀌면 승인하지 않는다.
- 상품: `coupon1`(1,000원·1장), `coupon3`(3,000원·3장). 가격을 바꾸려면 `tripkku_order_create` 함수.
