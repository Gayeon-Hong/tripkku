# 출시에 필요한 개인정보 및 보안 작업 (초안)

이 문서는 개인정보 처리방침 자체가 아니며 출시 전 체크리스트입니다.

1. 개인정보 최소 수집: 로그인 계정 ID와 선택한 닉네임, 여행 일정/예산. 항공권 가격은 개별 계정만 읽도록 제한.
2. 초대 링크는 소유자가 발급. 사용자가 합류하면 멤버 목록에 표시. 토큰 분실/유출 시 폐기 기능 추가 필요.
3. 계정 탈퇴 / 여행방 나가기 / 여행방 삭제 / 개인정보 다운로드 기능 추가 필요.
4. PostgreSQL RLS + 감사 로그 / 권한 테스트 / 서비스 DB 백업 / 오류 추적 구축 필요.
5. OAuth Client Secret, Toss private key, Supabase service_role 및 AI API 키는 **서버 비밀 저장소**에서만 관리.
6. AI 대화 기록을 저장하면 목적·보유 기간·처리 위탁·데이터 국외 이전 가능성을 검토.
7. 여행 날짜와 장소 데이터는 사생활 정보이므로 검색엔진 색인 및 공개 URL 자동 게시 금지.
8. 현재 공개 소스는 친구 개인 지도·원본 블로그 링크·실제 예약 상세를 제거한 샘플입니다.
9. 공동경비는 단순 예상·기록 기능입니다. 송금/결제는 구현하지 않았습니다.
10. 앱인토스 토스 로그인 해제/서비스 탈퇴 정책을 구현하고 개발자 콘솔 체크리스트를 확인하세요.
