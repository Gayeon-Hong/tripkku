# 트립꾸 · 푸시 알림 (2026-11-12)

코드는 들어가 있고 **알림 버튼은 꺼져 있다**(`next/app.js` 의 `PUSH.publicKey` 가 비어 있음). 아직 실제 기기로 보내 보지 못했다.

## 직접 해야 하는 것
1. **키 만들기**: https://gayeon-hong.github.io/tripkku/next/vapid.html 을 열고 "키 한 쌍 만들기". (브라우저 안에서만 만들어지고 어디로도 전송되지 않음)
2. **SQL 실행**: Supabase → SQL Editor → `sql/2026-11-12_push.sql`.
3. **서버 함수 올리기**: Supabase → Edge Functions → 새 함수 `tripkku-push` → `supabase/functions/tripkku-push/index.ts` 내용 붙여넣고 배포.
4. **비밀 값**: Supabase → Edge Functions → Secrets 에 `VAPID_PUBLIC_KEY`(공개 키), `VAPID_PRIVATE_KEY`(비밀 키), `VAPID_SUBJECT`(`mailto:문의 이메일`).
5. **공개 키만 Claude 에게 알려 주기** → `PUSH.publicKey` 에 넣으면 홈에 "🔕 알림 받기" 버튼이 생긴다.

## 언제 누구에게 가는지 (서버가 정함)
| 일 | 받는 사람 |
|---|---|
| 새 여행 등록 | 트립꾸 관리자 |
| 디테일 제작 요청 | 트립꾸 관리자 |
| 초대로 새 일행 참여 | 여행 만든 사람 |
| 일정 변경 | 다른 일행 (여행당 30분에 한 번) |

- 알림은 기기마다 "알림 받기"를 눌러야 온다. 아이폰은 홈 화면에 추가한 앱에서만 된다(iOS 16.4 이상).
- 앱은 "무슨 일(kind) + 여행 id"만 보내고, 글과 받는 사람은 서버가 정한다. 그 여행 사람만 알림을 일으킬 수 있고 한 사람당 1시간 30번까지.
- 디테일 제작이 끝났을 때 요청자에게 가는 알림은 아직 없다(3D는 코드로 올라가서 서버가 알 수 없음).
