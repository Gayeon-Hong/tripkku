# Tripkku 표정 지구 복구 패치

이번 패치는 **표정 지구 모드에 필요한 배경 이미지 2개를 빠뜨렸던 문제**를 해결합니다.
지도 지구, 날씨, 일정, Supabase 설정, 로그인 코드에는 손대지 않습니다.

## GitHub Desktop 적용

1. 압축을 풀고, `Repository > Show in Explorer`로 열린 현재 tripkku 저장소 최상위에 있는 파일/폴더에 덮어씁니다.
2. `assets/earth-base-light.png`, `assets/earth-base-dark.png`가 실제로 복사됐는지 확인합니다.
3. GitHub Desktop 변경 목록에서 새 PNG 2개, `earth-avatar.js`, `style.css`, `sw.js`를 확인합니다. (앱인토스용 동일 파일도 포함)
4. Summary에 `Fix character globe assets` 입력 -> Commit to main -> Push origin.
5. 웹에서 Ctrl+Shift+R 후, `표정 지구` 모드에서 신남/화남/졸림/설렘을 바꿔봅니다.
6. 안 보이면 아래 PNG 주소를 직접 열어 표시되는지 확인하세요.
   - https://gayeon-hong.github.io/tripkku/assets/earth-base-light.png
   - https://gayeon-hong.github.io/tripkku/assets/earth-base-dark.png

### 주의
- `config.js`와 Supabase URL, 키는 이 ZIP에 없으며 덮어쓰지 않습니다.
- 지도 모드는 그대로 유지됩니다.
- 캐시를 피하려고 서비스워커 버전을 올렸습니다. **사이트 데이터 초기화는 하지 마세요.**
- 토스의 기존 `.ait` 파일은 GitHub를 고쳐도 자동 갱신되지 않습니다.
