가마지옥은 벳푸시 간나와, 유후 모미지는 유후인 가와키타, MYSTAYS는 오이타 시내에 있어요. 현재 예약은 그대로 유지합니다.

숙소가 가마지옥 근처로 변경되고 체크인 전 보관을 허용할 때만 숙소에 맡기는 경로로 바꾸세요. 현재 예약에서는 가까운 숙소라는 가정을 하지 않습니다.

WANDER COMPASS의 짐 보관은 별도 유료 서비스입니다. 당일 접수·크기별 요금·회수 마감은 현장 확인이 필요하며, 예상 보관료는 정산에 자동 추가하지 않습니다.
