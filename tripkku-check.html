🔑 Google 로그인 확인 위치

Google Cloud → OAuth 클라이언트
Client ID는 ...apps.googleusercontent.com 형식이어야 해. 승인된 리디렉션 URI는 GitHub 주소가 아니라 Supabase의 /auth/v1/callback 주소야.

Supabase → Authentication → Providers → Google
활성화하고 Google의 Client ID와 Secret을 등록해야 해.

Supabase → Authentication → URL Configuration
Site URL과 Redirect URLs에 https://gayeon-hong.github.io/tripkku/를 등록해야 해.

공개용 Supabase 키만 브라우저 설정에 사용할 수 있어. Google Client Secret·Gemini 키·service_role 키는 절대 GitHub에 올리면 안 돼.
