# QA 기록 (2026-10-26)

## 이 환경에서 검증한 항목 (정적 데모 + 브라우저 시뮬레이션)

- Chromium 데스크톱 1440x900, 모바일 390x844, 작은 모바일 320x700.
- 화면의 가로 넘침 없음.
- 오이타 A/B 숙소 변경 시 객실가격과 예산 계산 연결.
- 공동 예산/개인 예산을 낮추면 초과금이 붉게 표시됨.
- 금액을 입력하는 즉시 초과 예상 금액 표시.
- 개인 항공권 금액 입력 후 비용에 가산.
- 료칸 금액을 35만원으로 바꾸는 명령어 및 A/B 결합 명령어 동작.
- 핑크 테마 전환.
- 런던 샘플에서 영어 회화 전환, 오이타 항공편 숨김.
- JS 브라우저 런타임 오류 없음(데모 시나리오 기준).

## 실제 외부 연동 검증은 아직 하지 못한 항목

- Supabase 서버 생성/SQL 실제 적용, SNS 공급자 Google/Kakao OAuth 승인
- 초대 링크를 통해 실제 계정 2개로 멤버 추가 및 실시간 DB 동기화
- 계정별 개별 예산/항공권의 RLS 침해 테스트
- 실사용 안드로이드/iPhone PWA 설치, Safari/OAuth 복귀 흐름
- TossAuth.login() 서버 검증, Toss SDK `.ait` 번들, 토스 샌드박스·실기기 테스트
- 앱인토스 외부 링크 정책/비게임 출시 심사
- 항공편/호텔 예약의 실제 가격·재고·날짜별 최신 운영 여부

**즉, 현재 패키지는 출시 준비를 위한 작동하는 시제품이며 실제 운영 승인 완료본은 아닙니다.**
